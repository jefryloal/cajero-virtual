# 🏧 Cajero Virtual (Simulador ATM)

Aplicación web interactiva que simula las operaciones principales de un cajero automático, con sistema de registro, inicio de sesión, validaciones de saldo y persistencia de cuentas y movimientos mediante `localStorage`.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de formularios y paneles.
* **CSS3:** Estilos de tarjetas, botones y alertas visuales.
* **JavaScript (ES6+):** Lógica bancaria, manipulación dinámica del DOM y almacenamiento local (`localStorage`).

## ✨ Funcionalidades Principales

* **Autenticación Local:** Registro de nuevos usuarios e inicio de sesión con validación de credenciales.
* **Gestión de Saldo:** Consulta en tiempo real, consignaciones y retiros con validación de fondos disponibles.
* **Transferencias:** Envío de dinero entre usuarios registrados en el sistema.
* **Historial de Movimientos:** Registro detallado de cada transacción realizada por el usuario.

## 🚀 Ejecución

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` directamente en tu navegador web o ejecútalo con **Live Server** en Visual Studio Code.
